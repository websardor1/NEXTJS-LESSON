# 🔤 NEXT.JS 4-DARS | FONT BILAN ISHLASH — SAYTIMIZGA PROFESSIONAL SHRIFTLAR ULAYMIZ! 🚀

Assalomu alaykum, dasturchilar! 👋

NEXT.JS bo‘yicha to‘liq kursimizning **4-darsiga xush kelibsiz!**

Ushbu darsimizda Next.js loyihalarida Font (shriftlar) bilan ishlashni o‘rganamiz. Har qanday zamonaviy web saytning chiroyli ko‘rinishida shriftlarning o‘rni juda katta. To‘g‘ri tanlangan shrift sayt dizaynini yanada professional, zamonaviy va foydalanuvchilar uchun qulay qiladi.

Next.js bizga shriftlar bilan ishlash uchun juda qulay imkoniyatlarni taqdim etadi. Ayniqsa, `next/font` yordamida Google Fonts va lokal shriftlarni loyihamizga osongina ulashimiz mumkin.

Ushbu darsda barcha jarayonlarni noldan boshlab, amaliy kodlar yordamida o‘rganamiz.

✅ Font nima va u nima uchun kerak?

💡 **Nima uchun Next.js Font'dan foydalanamiz?**

Next.js'dagi `next/font` shriftlarni optimallashtirishga yordam beradi. Bu esa tashqi shrift xizmatlariga bog‘liqlikni kamaytiradi va sayt ishlash samaradorligini yaxshilashga xizmat qiladi.
